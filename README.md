# MoveWest Creative Dance page

This is a static GitHub Pages site. The page is `index.html`; its six image files are in `images/`. Keep that folder name and its filenames unchanged when uploading.

## Before publishing

The eight-class schedule runs October 17 through December 12, 2026, with no class November 28 (Thanksgiving weekend). Verify the studio's `X-2` unit designation from the supplied copy.

## Create the repository and publish

1. Sign in to GitHub under the account or organization that should own the page. Select **New repository**. A name such as `movewest-creative-dance` is fine. Choose **Public**, and create it without adding a README, `.gitignore`, or license.
2. On the new repository page choose **Add file → Upload files**. Open this package's `movewest-creative-dance` folder on your computer, then drag **`index.html`, `README.md`, and the entire `images` folder** into the upload area. Check that GitHub shows `images/body.png`, `images/energy.png`, and the other image paths under `images/`, not at the repository root. Commit the upload to the default branch.
3. Open **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**; select the default branch (usually `main`) and **/(root)**; then save.
4. Wait for GitHub Pages to show the public address. It normally follows `https://ACCOUNT.github.io/movewest-creative-dance/`, where `ACCOUNT` is the owning user or organization. Open that address on a phone as well as a computer. Check the images, times, email button, and the no-class date before sharing it.

The page has no forms, scripts, analytics, external fonts, or required build step. Registration forms are available at MOVE Studio and payment is made there. To change text later, edit `index.html` in GitHub and commit; to replace an image, upload a file with the same path and name.
